# Spa Reservation System

A Java client-server application for managing spa reservations, developed as a university Computer Networks team project.

The system uses TCP sockets for communication between clients and a central server, with a Java Swing interface for browsing services and managing reservations.

## Features

- Register an account and log in.
- Browse five spa services: Manicure, Pedicure, Massage, Facial, and Reflexology.
- View available slots by service.
- Reserve a slot with a selected therapist.
- View and cancel personal reservations.
- Handle multiple client connections using a separate thread for each client.
- Save and reload user accounts and reservations using Java serialization.

## Getting Started

### Requirements

- JDK 24, as configured in `pom.xml`.
- NetBeans or another Java IDE with Maven support.

### Running in NetBeans

1. Clone this repository or download and extract its ZIP archive.
2. Open the project folder containing `pom.xml` in NetBeans.
3. Build the project.
4. Right-click `Server.java` and select **Run File**.
5. Keep the server running, then right-click `ClientTest.java` and select **Run File**.
6. Use the interface to register, log in, and manage reservations.

Run these files individually rather than using the project's default Run action.

The client connects to `localhost` on port `9090`. Start additional instances of `ClientTest.java` to try multiple clients on the same machine.

## How It Works

The client sends text-based requests to the server over a TCP connection. The server processes account and reservation requests through a shared reservation manager and returns responses to the client.

User accounts and reservation slots are stored in local `users.dat` and `slots.dat` files. These runtime files are generated by the application and are not included in the repository.

## Project Scope

This project demonstrates socket programming, multithreading, and a graphical client-server workflow in an academic setting. It uses predefined services, therapists, and weekly reservation slots.

It is a prototype intended for local demonstration and does not include payment processing or integration with a real spa.
